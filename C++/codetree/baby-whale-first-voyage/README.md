# Codetree - 아기 고래의 첫 항해

## 문제 설명

- [풀이 코드](./baby-whale-first-voyage.cpp)
- `N × N` 격자와 시작 위치 `(r, c)`, 시작 방향 `d`가 주어진다. 격자의 `0`은 이동할 수 있는 칸, `1`은 장애물이다.
- 방향 번호는 `1: 위`, `2: 아래`, `3: 왼쪽`, `4: 오른쪽`이며, 입력과 출력의 좌표는 1부터 시작한다.
- 현재 방향을 기준으로 **앞 → 왼쪽 → 오른쪽 → 뒤** 순서로 확인하여, 아직 방문하지 않은 인접 칸으로 이동한다. 이동한 방향이 새로운 현재 방향이 된다.
- 인접한 미방문 칸으로 이동할 수 없으면, 이미 방문한 칸을 통과하여 도달할 수 있는 가장 가까운 미방문 칸을 찾는다. 거리가 같으면 행이 작은 칸, 행도 같으면 열이 작은 칸을 선택한다.
- 선택한 목적지로 가는 최단 경로가 여러 개라면, 매 이동에서 **왼쪽 → 아래 → 오른쪽 → 위** 순으로 우선한다.
- 도달할 수 있는 미방문 칸이 없어지면 항해를 종료한다. 시작 위치를 포함하여 각 칸을 **처음 방문한 순서대로** 좌표를 출력한다.

## 아이디어

- **시뮬레이션 + BFS + 최단 경로 복원**으로 이동 규칙을 구현한다.
- 격자 자체에 방문 상태를 기록한다. `0`은 미방문 칸, `1`은 장애물, `-1`은 이미 방문한 칸이다.
- `move`는 현재 방향에 따른 우선순위로 미방문 칸을 계속 방문하고, 더 이동할 수 없을 때의 위치와 방향을 반환한다.
- `bfs`는 이동이 막힌 위치에서 가장 가까운 미방문 칸을 선택한다. `(거리, 행, 열)` 튜플을 비교하면 거리와 좌표의 우선순위를 한 번에 처리할 수 있다.
- 목적지를 선택한 뒤에는 `getDist`로 **목적지에서 출발하는 BFS**를 수행한다. 그러면 각 칸에서 목적지까지 남은 최단 거리를 알 수 있다.
- 현재 위치에서 거리가 정확히 1 줄어드는 이웃만 선택하면 최단 경로를 유지할 수 있다. 이웃을 왼쪽, 아래, 오른쪽, 위 순서로 확인하여 경로의 우선순위도 만족시킨다.
- 이미 방문한 칸은 목적지로 이동할 때 통과할 수 있지만, `answer`에는 새로 방문한 칸만 기록한다.

일반 이동과 목적지까지의 이동은 방향 우선순위의 기준이 다르다.

| 구분 | 방향 우선순위 | 이미 방문한 칸 통과 |
| --- | --- | --- |
| `move`의 일반 이동 | 현재 방향 기준 앞 → 왼쪽 → 오른쪽 → 뒤 | 불가능 |
| 목적지까지의 최단 경로 이동 | 격자 기준 왼쪽 → 아래 → 오른쪽 → 위 | 가능 |

## 시간복잡도

- 격자의 한 변의 길이를 `N`, 목적지를 다시 선택하여 이동하는 횟수를 `K`라고 한다.
- `move`에서 성공하는 이동은 항상 새로운 칸을 방문하므로, 전체 실행에서 최대 `N² - 1`번이다. 호출 및 종료 처리까지 포함한 일반 이동의 총 비용은 `O(N² + K)`이다.
- `bfs`와 `getDist`는 각각 최대 `N²`개의 칸을 탐색하므로 한 번에 `O(N²)`이다.
- 목적지로 이동할 때는 남은 거리가 매번 1 감소하므로, 한 번의 경로 복원도 최대 `O(N²)`이다.
- 마지막에 목적지가 없음을 확인하는 BFS까지 포함하면 전체 시간복잡도는 `O((K + 1) × N²)`이다. 목적지에 도착할 때마다 적어도 한 칸을 새로 방문하므로 `K = O(N²)`이며, **최악의 경우 시간복잡도 상한은 `O(N⁴)`**이다.
- 격자, 방문 배열, 거리 배열, BFS 큐, 최초 방문 좌표를 저장하는 `answer`는 각각 최대 `O(N²)` 크기이므로 **공간복잡도는 `O(N²)`**이다.

## 풀이 흐름

1. `N`, 시작 좌표 `(r, c)`, 시작 방향 `d`와 격자를 입력받는다.
2. 내부 계산을 위해 시작 좌표를 0부터 시작하도록 변환하고, 시작 위치를 `answer`에 기록한다.
3. `move(r, c, d, map)`으로 방향 우선순위에 따라 미방문 칸을 연속해서 방문한다.
4. 이동이 멈춘 위치에서 `bfs`를 호출하여 다음 목적지 `(tr, tc)`를 찾는다.
5. 목적지가 `(-1, -1)`이면 더 방문할 수 있는 칸이 없으므로 반복을 종료한다.
6. `getDist(tr, tc, map)`으로 모든 이동 가능한 칸에서 목적지까지의 최단 거리를 계산한다.
7. 현재 위치에서 왼쪽, 아래, 오른쪽, 위 순으로 확인하며 거리가 1 감소하는 칸으로 이동한다. 이동할 때마다 방향도 갱신한다.
8. 이동 중 처음 방문한 칸은 `-1`로 표시하고 `answer`에 좌표를 추가한다.
9. 목적지에 도착한 위치와 마지막 이동 방향을 다음 `move`의 시작 상태로 사용한다.
10. 항해가 끝나면 `answer`에 저장된 좌표를 순서대로 출력한다.

## 코드 설명

### 1. 현재 방향에 따른 일반 이동

```cpp
vector<vector<int>> turn = {
    {1, 2, 3, 4},
    {3, 4, 2, 1},
    {4, 3, 1, 2},
    {2, 1, 4, 3}
};
int dr[4] = {-1, 1, 0, 0};
int dc[4] = {0, 0, -1, 1};

int curDir = turn[i][dir - 1];
int nr = r + dr[curDir - 1];
int nc = c + dc[curDir - 1];
```

- `turn`의 행 `i`는 앞, 왼쪽, 오른쪽, 뒤의 우선순위를 나타내고, 열 `dir - 1`은 현재 바라보는 방향을 나타낸다.
- 예를 들어 위쪽인 `dir = 1`을 바라보면 `1 → 3 → 4 → 2`, 즉 위 → 왼쪽 → 오른쪽 → 아래 순서로 확인한다.
- 아래쪽인 `dir = 2`를 바라보면 `2 → 4 → 3 → 1`이므로 아래 → 오른쪽 → 왼쪽 → 위 순서가 된다.
- 격자 밖, 장애물, 이미 방문한 칸은 건너뛴다. 이동에 성공하면 위치와 방향을 갱신하고 해당 칸을 `-1`로 표시한다.
- 네 방향 모두 이동할 수 없으면 현재 `(r, c, dir)`을 반환한다.

### 2. 다음 목적지 선택

```cpp
tuple<int, int, int> best = {51 * 51, 50, 50};

while (!q.empty()) {
    auto [row, col, dist] = q.front();
    q.pop();

    if (dist > get<0>(best)) break;
    if (graph[row][col] == 0) {
        best = min(best, make_tuple(dist, row, col));
        continue;
    }
    // 장애물이 아니며 이번 BFS에서 아직 탐색하지 않은 이웃을 큐에 추가한다.
}
```

- 큐에는 `(행, 열, 시작점으로부터의 거리)`를 저장하고, `best`에는 `(거리, 행, 열)`을 저장한다.
- 튜플은 앞의 원소부터 비교하므로 `min`으로 최단 거리, 작은 행, 작은 열 순서의 목적지를 선택한다.
- 처음 미방문 칸을 발견하더라도 즉시 반환하지 않고, 같은 거리의 후보를 모두 비교한다.
- BFS는 거리 순서대로 탐색하므로 `dist > get<0>(best)`가 되면 이후 후보는 더 가까울 수 없어 종료한다.
- 미방문 칸을 발견한 뒤에는 그 칸 너머를 탐색하지 않는다. 그 너머의 칸은 지금 발견한 미방문 칸보다 멀기 때문에 다음 목적지가 될 수 없다.
- `graph`의 `-1`은 항해 중 방문한 상태이고, `visited`는 이번 BFS에서 탐색한 상태이다. 목적지 탐색에서는 `-1`인 칸도 통과할 수 있다.
- `best`의 거리가 초기값 `51 * 51` 그대로이면 목적지를 찾지 못한 것이므로 `(-1, -1)`을 반환한다.

### 3. 목적지에서부터 거리 계산

```cpp
vector<vector<int>> dist(N, vector<int>(N, -1));
q.push({r, c});
dist[r][c] = 0;

// getDist의 BFS 내부
if (dist[nr][nc] != -1 || graph[nr][nc] == 1) continue;
dist[nr][nc] = dist[row][col] + 1;
q.push({nr, nc});
```

- `getDist`의 시작점 `(r, c)`에는 선택한 목적지 `(tr, tc)`를 전달한다.
- 장애물을 제외한 칸 사이의 이동은 양방향이므로, 목적지에서 어떤 칸까지의 최단 거리는 그 칸에서 목적지까지의 최단 거리와 같다.
- 거리 배열의 `-1`은 아직 거리가 계산되지 않았거나 도달할 수 없는 칸을 뜻한다. 격자의 방문 표시 `-1`과는 별개이다.
- `graph[nr][nc] == 1`인 칸만 막기 때문에 항해 중 이미 방문한 칸도 거리 계산에 포함된다.

### 4. 우선순위에 따른 최단 경로 복원

```cpp
int turn[4] = {3, 2, 4, 1};

while (row != tr || col != tc) {
    for (int i = 0; i < 4; ++i) {
        int curDir = turn[i];
        int nr = row + dr[curDir - 1];
        int nc = col + dc[curDir - 1];
        if (nr < 0 || nr >= N || nc < 0 || nc >= N) continue;
        if (dist[nr][nc] != dist[row][col] - 1) continue;

        row = nr;
        col = nc;
        dir = curDir;
        if (map[row][col] == 0) {
            map[row][col] = -1;
            answer.push_back({row + 1, col + 1});
        }
        break;
    }
}
```

- `turn = {3, 2, 4, 1}`은 격자 기준 왼쪽 → 아래 → 오른쪽 → 위 순서이다.
- 목적지까지의 거리가 1 감소하는 이웃은 모두 최단 경로의 다음 칸이 될 수 있다. 그중 우선순위가 가장 높은 칸을 선택하고 `break`한다.
- 목적지에 도착하기 전에는 현재 거리가 양수이고, 선택할 다음 거리도 0 이상이다. 장애물의 거리는 `-1`로 남아 있으므로 거리 조건만으로도 장애물로 이동하는 것을 막을 수 있다.
- 이미 방문한 칸을 지나갈 때도 `dir`은 갱신한다. 목적지 도착 직전의 이동 방향이 이후 일반 이동의 기준이 되기 때문이다.
- `answer`에는 `map[row][col] == 0`인 경우에만 추가한다. 따라서 재방문 경로는 출력되지 않으며, 좌표에 1을 더해 입력과 같은 좌표 체계로 기록한다.
