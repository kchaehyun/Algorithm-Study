# Programmers 87946 - 피로도

## 문제 설명
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/87946)
- 현재 피로도 `k`와 각 던전의 `최소 필요 피로도`, `소모 피로도`가 주어진다.
- 던전을 탐험하려면 현재 피로도가 해당 던전의 최소 필요 피로도 이상이어야 한다.
- 던전을 탐험한 후에는 소모 피로도만큼 현재 피로도가 감소한다.
- 주어진 피로도로 탐험할 수 있는 최대 던전 수를 반환한다.

## 아이디어
- 던전을 탐험하는 순서에 따라 탐험할 수 있는 던전 수가 달라지므로 가능한 모든 순서를 확인한다.
- `visited` 배열을 사용하여 현재 탐험 경로에 포함된 던전을 표시한다.
- 현재 피로도가 던전의 최소 필요 피로도 이상인 경우에만 해당 던전을 탐험한다.
- 던전을 선택한 뒤 소모 피로도를 뺀 상태로 DFS를 호출한다.
- 재귀 호출이 끝나면 방문 표시를 해제하여 다른 탐험 순서에서도 해당 던전을 선택할 수 있게 한다.
- 탐험한 던전 수의 최댓값을 매 DFS 호출마다 갱신한다.

## 풀이 과정
1. 초기 피로도 `k`와 탐험한 던전 수 0으로 DFS를 시작한다.
2. 현재까지 탐험한 던전 수로 `answer`의 최댓값을 갱신한다.
3. 모든 던전을 순회하며 아직 방문하지 않은 던전을 찾는다.
4. 현재 피로도가 해당 던전의 최소 필요 피로도 이상인지 확인한다.
5. 탐험할 수 있다면 방문 처리하고, 소모 피로도를 뺀 값으로 DFS를 호출한다.
6. 재귀 호출이 끝나면 방문 처리를 해제하여 다음 경우의 수를 탐색한다.
7. 모든 가능한 탐험 순서를 확인한 뒤 최대 탐험 횟수를 반환한다.

## 코드 설명
```cpp
int answer = 0;
vector<bool> visited(8, false);

void dfs(int tired, int num, vector<vector<int>>& dungeons) {
    answer = max(answer, num);
    for (int i = 0; i < dungeons.size(); ++i) {
        if (!visited[i] && tired >= dungeons[i][0]) {
            visited[i] = true;
            dfs(tired - dungeons[i][1], num + 1, dungeons);
            visited[i] = false;
        }
    }
}

int solution(int k, vector<vector<int>> dungeons) {
    dfs(k, 0, dungeons);
    return answer;
}
```
- `answer`는 현재까지 탐험할 수 있었던 던전 수의 최댓값이다.
- `visited[i]`는 현재 탐험 순서에서 `i`번째 던전을 이미 방문했는지 나타낸다.
- `tired`는 현재 남아 있는 피로도이고, `num`은 현재까지 탐험한 던전 수이다.
- `tired >= dungeons[i][0]`을 통해 현재 피로도로 던전에 입장할 수 있는지 확인한다.
- 재귀 호출에는 `dungeons[i][1]`만큼 피로도를 소모한 값과 1 증가한 탐험 횟수를 전달한다.
- 재귀 호출 후 `visited[i]`를 다시 `false`로 바꾸는 백트래킹을 통해 다른 탐험 순서를 확인한다.

## 시간복잡도
- 던전의 개수를 `N`이라고 하면 가능한 던전 순서를 모두 탐색하고 각 상태에서 최대 `N`개의 던전을 확인하므로 O(N · N!)이다.
- 던전의 개수가 최대 8개이므로 완전 탐색으로 충분히 해결할 수 있다.
