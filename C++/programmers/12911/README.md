# Programmers 12911 - 다음 큰 숫자

## 문제 설명
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12911)
- 자연수 `n`이 주어진다.
- `n`보다 큰 자연수 중에서 이진수로 변환했을 때 `1`의 개수가 `n`과 같은 수를 찾아 반환한다.
- 조건을 만족하는 수 중 가장 작은 수가 정답이다.

## 아이디어
- 어떤 수의 이진수에서 `1`의 개수를 세는 함수 `oneCnt()`를 만든다.
- 정답 후보를 `n + 1`부터 시작한다.
- `n`의 `1` 개수와 후보 숫자의 `1` 개수가 같아질 때까지 후보를 `1`씩 증가시킨다.
- 두 개수가 같아지는 첫 번째 수가 `n`보다 큰 수 중 가장 작은 정답이다.

## 시간복잡도
- 정답을 찾을 때까지 후보 숫자를 하나씩 확인한다.
- 각 후보마다 이진수의 비트 수만큼 나누기 연산을 수행하므로 `oneCnt()`는 O(log N)이다.
- 후보를 확인한 횟수를 `K`라고 하면 전체 시간복잡도는 O(K log N)이다.
- 별도의 자료구조를 사용하지 않으므로 공간복잡도는 O(1)이다.

## 풀이 과정
1. `oneCnt()` 함수에서 숫자를 2로 나누며 나머지가 1인 경우를 센다.
2. `solution()`에서 정답 후보 `answer`를 `n + 1`로 초기화한다.
3. `oneCnt(n)`과 `oneCnt(answer)`가 다르면 `answer`를 `1` 증가시킨다.
4. 두 값이 같아지는 순간 반복을 멈추고 `answer`를 반환한다.

## 코드 설명
```cpp
int oneCnt(int n) {
    int cnt = 0;
    while(n > 0) {
        if(n%2) ++cnt;
        n /= 2;
    }
    return cnt;
}

int solution(int n) {
    int answer = n+1;
    while(oneCnt(n) != oneCnt(answer)) ++answer;
    return answer;
}
```
- `oneCnt()`는 `n`을 2로 나누면서 현재 비트가 `1`인지 확인한다.
- `n % 2`가 `1`이면 이진수의 현재 자리 값이 `1`이므로 `cnt`를 증가시킨다.
- `solution()`은 `n + 1`부터 차례대로 확인해 `n`보다 큰 숫자만 검사한다.
- 처음으로 `1`의 개수가 같아진 `answer`가 조건을 만족하는 가장 작은 숫자이다.
