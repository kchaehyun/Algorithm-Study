# Programmers 70129 - 이진 변환 반복하기

## 문제 설명
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/70129)
- `0`과 `1`로 이루어진 문자열 `s`가 주어진다.
- `s`가 `"1"`이 될 때까지 다음 이진 변환을 반복한다.
- 먼저 `s`에서 모든 `0`을 제거한다.
- 제거 후 남은 문자열의 길이를 이진수로 바꾸어 새로운 `s`로 만든다.
- 이진 변환을 수행한 횟수와 변환 과정에서 제거된 `0`의 총개수를 배열에 담아 반환한다.

## 아이디어
- 변환 한 번마다 문자열을 순회하면서 `0`의 개수를 세고, `1`만 남긴 문자열을 만든다.
- `0`을 제거한 뒤 남은 문자열의 길이가 다음 변환에 사용할 숫자이다.
- 이 숫자를 2로 나누며 나머지를 저장하면 이진수 문자열을 만들 수 있다.
- 문자열이 `"1"`이 되는 순간 더 이상 변환할 필요가 없으므로 반복을 종료한다.

## 풀이 과정
1. 변환 횟수 `i`와 제거한 `0`의 총개수 `zero`를 `0`으로 초기화한다.
2. `s`가 `"1"`이 아닌 동안 반복한다.
3. 변환 횟수 `i`를 `1` 증가시킨다.
4. 문자열 `s`를 순회하며 `0`은 `zero`에 더하고, `1`은 임시 문자열 `str`에 저장한다.
5. `str`의 길이를 구해 이진수 문자열로 변환한다.
6. 변환된 이진수 문자열을 다시 `s`에 저장한다.
7. 반복이 끝나면 `{i, zero}`를 반환한다.

## 코드 설명
```cpp
vector<int> solution(string s) {
    int i = 0;
    int zero = 0;
    while(s != "1") {
        ++i;
        string str;
        for(char c : s) {
            if(c == '0') {
                ++zero;
                continue;
            }
            str.push_back(c);
        }
        int num = str.size();
        string tmp;
        while(num > 0) {
            tmp.push_back((num%2) + '0');
            num /= 2;
        }
        reverse(tmp.begin(), tmp.end());
        s = tmp;
    }
    return {i,zero};
}
```
- `while (s != "1")`은 이진 변환을 반복해야 하는 조건이다.
- `zero`는 변환 과정 전체에서 제거한 `0`의 개수를 누적한다.
- `str`에는 `0`을 제거하고 남은 `1`만 저장한다.
- `num = str.size()`는 다음 문자열로 변환할 십진수 값이다.
- `tmp.push_back((num % 2) + '0')`는 `num`을 2로 나눈 나머지를 문자로 저장한다.
- 나머지는 뒤에서부터 구해지므로 `reverse`로 뒤집어 올바른 이진수 문자열을 만든다.
- 마지막에 `{i, zero}`를 반환해 변환 횟수와 제거한 `0`의 개수를 함께 전달한다.

## 시간복잡도
- 각 변환마다 현재 문자열을 한 번 순회하고, 남은 길이를 이진수로 변환한다.
- 문자열의 길이는 변환이 진행될수록 빠르게 줄어들기 때문에 전체 시간복잡도는 O(N)으로 볼 수 있다.
- 임시 문자열을 사용하므로 공간복잡도는 O(N)이다.
