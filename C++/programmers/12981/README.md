# Programmers 12981 - 영어 끝말잇기

## 문제 설명
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12981)
- `n`명의 사람이 순서대로 돌아가며 영어 끝말잇기를 진행한다.
- 앞사람이 말한 단어의 마지막 문자로 시작하는 단어를 말해야 한다.
- 이전에 등장한 단어는 다시 사용할 수 없다.
- 가장 먼저 규칙을 어긴 사람의 번호와 그 사람이 몇 번째 차례에 탈락했는지를 반환한다.
- 끝까지 탈락자가 없다면 `{0, 0}`을 반환한다.

## 아이디어
- 지금까지 나온 단어를 `set`에 저장하여 중복 여부를 확인한다.
- 직전에 나온 단어의 마지막 문자를 `before`에 저장한다.
- 현재 단어의 첫 문자가 `before`와 다르거나, 현재 단어가 이미 `set`에 존재하면 탈락이다.
- 단어의 인덱스가 `i`일 때 사람 번호는 `i % n + 1`, 차례는 `i / n + 1`로 계산할 수 있다.

## 시간복잡도
- 단어의 개수를 `W`라고 하면 각 단어를 `set`에서 검색하고 삽입하는 데 O(log W)가 걸리므로 시간복잡도는 O(W log W)이다.
- 지금까지 등장한 단어를 `set`에 저장하므로 공간복잡도는 O(W)이다.

## 풀이 과정
1. 첫 번째 단어를 `set`에 넣고, 해당 단어의 마지막 문자를 `before`에 저장한다.
2. 두 번째 단어부터 순서대로 확인한다.
3. 현재 단어의 첫 문자가 `before`와 다른지 확인한다.
4. 현재 단어가 이미 `set`에 저장되어 있는지 확인한다.
5. 두 조건 중 하나라도 만족하면 현재 인덱스로 사람 번호와 차례를 계산하여 반환한다.
6. 규칙을 지켰다면 현재 단어를 `set`에 넣고 `before`를 현재 단어의 마지막 문자로 갱신한다.
7. 모든 단어가 규칙을 지켰다면 `{0, 0}`을 반환한다.

## 코드 설명
```cpp
vector<int> solution(int n, vector<string> words) {
    set<string> s;
    s.insert(words[0]);
    char before = words[0][words[0].size()-1];
    
    for(int i = 1 ; i < words.size() ; ++i) {
        if(words[i][0] != before || s.find(words[i]) != s.end())
            return {i%n + 1, i/n + 1};
        s.insert(words[i]);
        before = words[i][words[i].size()-1];
    }

    return {0,0};
}
```
- `s.find(words[i]) != s.end()`로 현재 단어가 이전에 등장했는지 검사한다.
- `words[i][0] != before`로 끝말잇기 규칙을 지켰는지 검사한다.
- `i % n + 1`은 탈락한 사람의 번호이고, `i / n + 1`은 그 사람의 탈락 차례이다.
- 규칙을 어긴 단어를 발견하는 즉시 결과를 반환한다.
- 반복문이 끝날 때까지 탈락자가 없으면 `{0, 0}`을 반환한다.
