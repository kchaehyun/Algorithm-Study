# Programmers 49994 - 방문 길이

## 문제 설명
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/49994)
- 캐릭터가 좌표평면 위에서 `U`, `D`, `R`, `L` 명령에 따라 이동한다.
- 좌표는 `-5` 이상 `5` 이하의 범위만 유효하다.
- 범위를 벗어나는 명령은 무시한다.
- 캐릭터가 처음 걸어본 길의 길이를 구한다.

## 아이디어
- 좌표 범위가 `-5`부터 `5`까지이므로 배열 인덱스로 사용하기 위해 좌표를 `0`부터 `10`까지로 옮겨서 생각한다.
- 이미 방문한 좌표가 아니라 이미 지나간 간선을 확인해야 한다.
- 예를 들어 `(x, y)`에서 `(nx, ny)`로 이동한 길은 반대로 `(nx, ny)`에서 `(x, y)`로 이동해도 같은 길이다.
- 따라서 이동할 때 현재 좌표의 방향과 다음 좌표의 반대 방향을 함께 방문 처리한다.
- 유효 범위 안으로 이동하면서 아직 방문하지 않은 간선이면 정답을 1 증가시킨다.

## 시간복잡도
- 명령 문자열 `dirs`를 한 번 순회하므로 O(N)
- `N`은 `dirs`의 길이다.

## 풀이 과정
1. `visited[11][11][4]` 배열로 각 좌표에서 4방향 간선 방문 여부를 저장한다.
2. 시작 위치는 원점 `(0, 0)`을 배열 인덱스에 맞게 옮긴 `(5, 5)`로 둔다.
3. `dirs`의 각 문자를 순회하며 다음 좌표와 현재 방향, 반대 방향을 계산한다.
4. 다음 좌표가 `0` 이상 `10` 이하 범위를 벗어나면 이동하지 않는다.
5. 범위 안이라면 현재 좌표에서 해당 방향으로 간 적이 있는지 확인한다.
6. 처음 지나가는 길이면 `answer`를 1 증가시키고, 현재 방향과 반대 방향을 모두 방문 처리한다.
7. 현재 위치를 다음 좌표로 갱신한다.
8. 모든 명령을 처리한 뒤 `answer`를 반환한다.

## 코드 설명
```cpp
int solution(string dirs) {
    int answer = 0;
    bool visited[11][11][4] = { false };
    int x = 5, y = 5;
    for(char c : dirs) {
        int nx = x, ny = y;
        int dir, rev;
        if(c == 'U') {
            ++ny;
            dir = 0;
            rev = 1;
        }
        else if(c == 'D') {
            --ny;
            dir = 1;
            rev = 0;
        }
        else if(c == 'R') {
            ++nx;
            dir = 2;
            rev = 3;
        }
        else if(c == 'L') {
            --nx;
            dir = 3;
            rev = 2;
        }
        
        if(0 <= nx && nx <= 10 && 0 <= ny && ny <= 10) {
            if(!visited[x][y][dir]) {
                ++answer;
                visited[x][y][dir] = true;
                visited[nx][ny][rev] = true;
            }
            x = nx;
            y = ny;
        }
    }
    return answer;
}
```
- `visited[x][y][dir]`은 `(x, y)`에서 `dir` 방향으로 이동한 길을 지나간 적이 있는지 저장한다.
- 같은 길을 반대 방향으로 다시 지나도 중복으로 세면 안 되므로 `visited[nx][ny][rev]`도 함께 `true`로 바꾼다.
- 좌표 범위를 벗어난 이동은 무시하고, 이때 현재 위치도 바꾸지 않는다.
- 처음 지나가는 간선만 `answer`에 더하므로 최종적으로 처음 걸어본 길의 개수를 구할 수 있다.
