# Programmers 12973 - 짝지어 제거하기

## 문제 설명
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12973)
- 문자열 `s`에서 같은 알파벳이 두 개 붙어 있는 짝을 찾아 제거한다.
- 문자열을 이어 붙인 뒤 같은 과정을 반복했을 때 모든 문자를 제거할 수 있으면 `1`, 없으면 `0`을 반환한다.
## 아이디어
- 문자열을 왼쪽부터 확인하면서 아직 짝을 찾지 못한 문자를 스택에 저장한다.
- 현재 문자와 스택의 맨 위 문자가 같다면 두 문자가 붙어 있는 짝이므로 스택의 문자를 제거한다.
- 두 문자가 다르거나 스택이 비어 있다면 현재 문자를 스택에 추가한다.
- 모든 문자를 확인한 뒤 스택이 비어 있으면 모든 짝이 제거된 것이고, 문자가 남아 있으면 모두 제거할 수 없는 경우이다.

## 시간복잡도
- 문자열의 길이를 `N`이라고 하면 각 문자는 스택에 최대 한 번 들어가고 한 번 제거되므로 시간복잡도는 O(N)이다.
- 스택에는 최대 `N`개의 문자가 저장될 수 있으므로 공간복잡도는 O(N)이다.

## 풀이 과정
1. 짝을 찾지 못한 문자를 저장할 `stack<char>`를 만든다.
2. 문자열 `s`의 문자를 처음부터 순회한다.
3. 스택이 비어 있지 않고 맨 위 문자와 현재 문자가 같으면 `pop()`하여 짝을 제거한다.
4. 그렇지 않으면 현재 문자를 스택에 넣는다.
5. 순회가 끝난 뒤 스택이 비어 있으면 `1`, 비어 있지 않으면 `0`을 반환한다.

## 코드 설명
```cpp
int solution(string s)
{
    stack<char> st;
    for(char c : s) {
        if(!st.empty() && st.top() == c)
            st.pop();
        else
            st.push(c);
    }
    if(!st.empty()) return 0;
    return 1;
}
```
- `st.top() == c`는 현재 문자와 바로 앞까지 처리한 문자열의 마지막 문자가 같은지 확인한다.
- 두 문자가 같으면 `st.pop()`으로 짝을 제거한다.
- 짝이 아니라면 `st.push(c)`로 현재 문자를 저장해 다음 문자와 비교한다.
- 마지막에 스택이 비어 있는지를 확인해 모든 문자가 짝을 이루어 제거되었는지 판단한다.
