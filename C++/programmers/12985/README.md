# Programmers 12985 - 예상 대진표

## 문제 설명
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12985)
- `N`명의 참가자가 토너먼트에 참가하며, 참가자 번호는 `1`번부터 `N`번까지이다.
- 각 라운드에서는 `1`번과 `2`번, `3`번과 `4`번처럼 인접한 번호의 참가자끼리 대결한다.
- 각 경기의 승자는 다음 라운드에서 새로운 번호를 부여받는다.
- 참가자 `A`와 `B`가 서로 만나기 전까지 항상 승리할 때, 두 참가자가 몇 번째 라운드에서 만나는지 반환한다.

## 아이디어
- 한 라운드가 끝난 뒤 참가자 번호 `x`는 `(x + 1) / 2`로 바뀐다.
- 예를 들어 `1`, `2`번 참가자는 다음 라운드에서 `1`번이 되고, `3`, `4`번 참가자는 `2`번이 된다.
- 따라서 `a`와 `b`에 이 계산을 반복하면 두 참가자가 다음 라운드에서 갖는 번호를 구할 수 있다.
- 두 번호가 같아지는 순간은 직전 라운드에서 두 참가자가 서로 대결했다는 뜻이다.
- 번호가 같아질 때까지 반복한 횟수가 두 참가자가 만나는 라운드이다.

## 시간복잡도
- 라운드마다 참가자 수가 절반으로 줄어들므로 시간복잡도는 O(log N)이다.
- 참가자 번호와 라운드 수만 저장하므로 공간복잡도는 O(1)이다.

## 풀이 과정
1. 라운드 수를 저장할 `answer`를 `0`으로 초기화한다.
2. `a`와 `b`가 서로 다른 동안 다음 과정을 반복한다.
3. `a`와 `b`를 각각 `(번호 + 1) / 2`로 갱신하여 다음 라운드의 번호를 구한다.
4. 라운드 수 `answer`를 `1` 증가시킨다.
5. 두 번호가 같아지면 반복을 종료하고 `answer`를 반환한다.

## 코드 설명
```cpp
int solution(int n, int a, int b)
{
    int answer = 0;

    while(a != b) {
        a = (a+1) / 2;
        b = (b+1) / 2;
        answer++;
    }

    return answer;
}
```
- `(a + 1) / 2`와 `(b + 1) / 2`는 현재 참가자의 다음 라운드 번호를 계산한다.
- 홀수 번호와 바로 다음 짝수 번호는 같은 값으로 변환되므로 같은 경기의 승자가 동일한 번호를 받는다.
- `while (a != b)`는 두 참가자가 같은 경기에서 만날 때까지 라운드를 진행한다.
- `answer`는 진행한 라운드의 수이며, 반복문이 끝났을 때 두 참가자가 만나는 라운드가 된다.
- 매개변수 `n`은 참가자 수를 나타내지만, 번호를 반복해서 절반으로 줄이는 풀이에서는 직접 사용할 필요가 없다.
