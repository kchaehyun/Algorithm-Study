# Programmers 60058 - 괄호 변환

## 문제 설명
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/60058)
- 균형잡힌 괄호 문자열 `p`가 주어진다.
- `(`와 `)`의 개수는 같지만, 올바른 괄호 문자열이 아닐 수 있다.
- 주어진 변환 규칙에 따라 `p`를 올바른 괄호 문자열로 변환해 반환한다.

## 아이디어
- 문자열을 가장 앞에서부터 탐색하며 `(`는 `+1`, `)`는 `-1`로 계산한다.
- 누적값이 처음으로 `0`이 되는 지점까지가 더 이상 쪼갤 수 없는 균형잡힌 문자열 `u`이다.
- 나머지 문자열은 `v`로 둔다.
- `u`가 올바른 괄호 문자열이면 `u + solution(v)`를 반환한다.
- `u`가 올바르지 않다면 문제의 변환 규칙대로 `(`, `solution(v)`, `)`를 붙인 뒤, `u`의 첫 문자와 마지막 문자를 제거하고 나머지 괄호 방향을 뒤집어 붙인다.
- 이 과정을 재귀적으로 반복하면 최종적으로 올바른 괄호 문자열이 만들어진다.

## 시간복잡도
- 문자열의 길이를 `N`이라고 하자.
- 각 재귀 단계에서 현재 문자열을 순회해 `u`, `v`를 나누고 `u`가 올바른지 검사한다.
- `substr`와 문자열 덧붙이기 비용까지 고려하면 최악의 경우 O(N^2)로 볼 수 있다.
- 문제의 문자열 길이 제한이 작기 때문에 재귀 풀이로 충분하다.

## 풀이 과정
1. 입력 문자열 `p`가 빈 문자열이면 빈 문자열을 반환한다.
2. `p`를 앞에서부터 순회하면서 `(`는 카운트를 증가시키고 `)`는 감소시킨다.
3. 카운트가 처음 `0`이 되는 위치를 기준으로 `u`와 `v`를 나눈다.
4. `correct(u)`로 `u`가 올바른 괄호 문자열인지 확인한다.
5. `u`가 올바르다면 `u + solution(v)`를 반환한다.
6. `u`가 올바르지 않다면 정답 문자열에 `(`를 먼저 추가한다.
7. 이어서 `solution(v)`의 결과와 `)`를 추가한다.
8. `u`의 첫 문자와 마지막 문자를 제외한 부분을 순회하며 괄호 방향을 반대로 바꿔 붙인다.
9. 만들어진 문자열을 반환한다.

## 코드 설명
```cpp
bool correct(string u) {
    int cnt = 0;
    for(char c : u) {
        if(c == '(') ++cnt;
        else --cnt;
        if(cnt < 0) return false;
    }
    if(!cnt) return true;
    return false;
}
```
- `correct`는 문자열이 올바른 괄호 문자열인지 검사한다.
- 왼쪽부터 확인할 때 `)`가 더 많아지는 순간 올바른 괄호 문자열이 아니므로 `false`를 반환한다.
- 끝까지 확인했을 때 카운트가 `0`이면 모든 괄호가 정상적으로 짝을 이룬 것이다.

```cpp
string solution(string p) {
    string answer = "";
    if(p == "") return "";
    int cnt = 0;
    string u, v;
    for(int i = 0 ; i < p.size() ; ++i) {
        if(p[i] == '(') ++cnt;
        else --cnt;
        if(!cnt) {
            u = p.substr(0,i+1);
            v = p.substr(i+1);
            break;
        }
    }
    if(correct(u)) return u + solution(v);
    else {
        answer += '(';
        answer += solution(v);
        answer += ')';
        for(int i = 1 ; i < u.size() - 1 ; ++i) {
            if(u[i] == '(') answer += ')';
            else answer += '(';
        }
    }
    return answer;
}
```
- `cnt`가 `0`이 되는 첫 지점까지 잘라 `u`를 만든다.
- `u`는 항상 균형잡힌 괄호 문자열이고, `v`는 남은 문자열이다.
- `u`가 올바르면 그대로 사용하고, `v`만 같은 규칙으로 변환한다.
- `u`가 올바르지 않으면 새 괄호쌍 안에 변환된 `v`를 넣고, `u`의 가운데 부분을 뒤집어 붙인다.
