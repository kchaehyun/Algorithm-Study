# Programmers 12951 - JadenCase 문자열 만들기

## 문제 설명
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12951)
- 문자열 `s`의 각 단어를 JadenCase 형식으로 바꾼다.
- 각 단어의 첫 문자가 알파벳이면 대문자로, 그 외의 알파벳은 소문자로 변환한다.
- 첫 문자가 숫자인 단어는 숫자는 그대로 두고, 뒤따르는 알파벳을 소문자로 변환한다.

## 아이디어
- 문자열을 왼쪽부터 한 번 순회하면서 각 문자의 위치에 따라 대소문자를 변환한다.
- 문자열의 첫 문자는 단어의 시작이므로 알파벳이면 대문자로 변환한다.
- 현재 문자의 바로 앞이 공백이면 새로운 단어의 시작이므로 현재 문자를 대문자로 변환한다.
- 그 외 위치의 알파벳은 단어의 첫 문자가 아니므로 소문자로 변환한다.
- 연속된 공백은 그대로 유지되며, 공백 다음 문자가 숫자여도 `toupper`를 적용한 결과는 변하지 않는다.

## 시간복잡도
- 문자열의 길이를 `N`이라고 할 때 문자열을 한 번 순회하므로 시간복잡도는 O(N)이다.
- 입력 문자열을 직접 수정하므로 추가 공간복잡도는 O(1)이다.

## 풀이 과정
1. 문자열의 첫 문자가 알파벳이면 대문자로 변환한다.
2. 두 번째 문자부터 문자열의 끝까지 순회한다.
3. 이전 문자가 공백이면 현재 문자를 단어의 첫 문자로 보고 대문자로 변환한다.
4. 이전 문자가 공백이 아니고 현재 문자가 알파벳이면 소문자로 변환한다.
5. 변환을 마친 문자열을 반환한다.

## 코드 설명
```cpp
string solution(string s) {
    if(isalpha(s[0])) s[0] = toupper(s[0]);
    for(int i = 1 ; i < s.size() ; ++i) {
        if(s[i-1] == ' ') s[i] = toupper(s[i]);
        else if(isalpha(s[i])) s[i] = tolower(s[i]);
    }
    return s;
}
```
- 첫 번째 `if`문은 문자열의 맨 앞 문자를 첫 단어의 시작 문자로 처리한다.
- 반복문은 이전 문자가 공백인지 확인하여 새로운 단어의 시작을 판별한다.
- 단어의 시작 문자는 `toupper`로 대문자화하고, 나머지 알파벳은 `tolower`로 소문자화한다.
- 숫자와 공백은 대소문자 변환의 영향을 받지 않으므로 원래 값이 유지된다.
