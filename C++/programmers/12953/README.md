# Programmers 12953 - N개의 최소공배수

## 문제 설명
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12953)
- 자연수로 이루어진 배열 `arr`가 주어진다.
- 배열에 들어 있는 모든 수의 최소공배수를 반환한다.

## 아이디어
- 배열의 각 수를 소인수분해한다.
- 최소공배수에는 각 소인수가 배열의 수들에서 나타난 횟수 중 가장 큰 지수만큼 포함되어야 한다.
- `unordered_map<int, int>`에 소인수를 키로, 해당 소인수의 최대 지수를 값으로 저장한다.
- 모든 수의 소인수분해가 끝나면 각 소인수를 저장된 최대 지수만큼 곱해 최소공배수를 구한다.

## 시간복잡도
- 배열의 길이를 `N`, 배열에서 가장 큰 수를 `M`이라고 할 때 소인수분해 과정의 시간복잡도는 O(N * M)이다.
- 소인수와 최대 지수를 저장하는 공간복잡도는 O(K)이다. `K`는 배열의 수들을 소인수분해했을 때 등장하는 서로 다른 소인수의 개수이다.

## 풀이 과정
1. 최소공배수를 저장할 `answer`를 `1`로 초기화한다.
2. 배열의 각 수 `a`에 대해 `2`부터 `a`까지 나누어 보며 소인수분해한다.
3. 현재 소인수 `i`로 나누어지는 동안 `a`를 나누고 지수 `cnt`를 증가시킨다.
4. `m[i]`에 기존 지수와 `cnt` 중 더 큰 값을 저장한다.
5. 모든 소인수분해가 끝나면 각 소인수를 저장된 최대 지수만큼 `answer`에 곱한다.
6. 완성된 최소공배수 `answer`를 반환한다.

## 코드 설명
```cpp
int solution(vector<int> arr) {
    int answer = 1;
    unordered_map<int,int> m;
    for(int a : arr) {
        for(int i = 2 ; i <= a ; ++i) {
            int cnt = 0;
            while(!(a%i)) {
                a /= i;
                ++cnt;
            }
            if(cnt != 0) m[i] = max(m[i], cnt);
        }
    }
    for(auto nums : m) {
        int num = nums.first;
        int times = nums.second;
        for(int i = 1 ; i <= times; ++i) answer *= num;
    }
    return answer;
}
```
- `m`은 각 소인수와 그 소인수에 필요한 최대 지수를 저장한다.
- `while(!(a%i))`는 `a`가 `i`로 나누어지는 동안 반복하여 소인수 `i`의 지수를 구한다.
- 같은 소인수가 여러 수에서 등장하면 `max(m[i], cnt)`로 가장 큰 지수만 남긴다.
- 마지막 반복문에서 각 소인수를 최대 지수만큼 곱하면 배열의 모든 수로 나누어지는 최소공배수가 완성된다.
