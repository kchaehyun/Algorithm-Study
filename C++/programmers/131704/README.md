# Programmers 131704 - 택배상자

## 문제 설명
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/131704)
- 택배상자는 `1`번부터 `n`번까지 번호 순서대로 컨테이너 벨트에 놓여 있다.
- 컨테이너 벨트의 맨 앞 상자만 꺼낼 수 있으며, 바로 트럭에 싣지 않는 상자는 보조 컨테이너 벨트에 보관할 수 있다.
- 보조 컨테이너 벨트는 마지막에 넣은 상자부터 꺼낼 수 있는 스택 구조이다.
- 기사님이 원하는 순서 `order`대로 상자를 실을 때, 실을 수 있는 상자의 최대 개수를 반환한다.

## 아이디어
- 기본 컨테이너 벨트는 앞에서부터 상자가 나오므로 `queue`로 표현한다.
- 보조 컨테이너 벨트는 마지막에 넣은 상자를 먼저 꺼내므로 `stack`으로 표현한다.
- 원하는 배송 순서 역시 `queue`에 저장하여 현재 실어야 할 상자를 항상 맨 앞에서 확인한다.
- 기본 벨트의 맨 앞 상자가 원하는 상자라면 바로 싣는다.
- 보조 벨트의 맨 위 상자가 원하는 상자라면 보조 벨트에서 꺼내 싣는다.
- 두 곳 모두 원하는 상자가 아니면 기본 벨트의 맨 앞 상자를 보조 벨트로 옮긴다.
- 기본 벨트가 비었는데 보조 벨트의 맨 위 상자도 원하는 상자가 아니라면 더 이상 작업할 수 없다.

## 풀이 과정
1. `1`번부터 `n`번까지의 상자를 기본 컨테이너 벨트 큐 `q`에 넣는다.
2. 원하는 상자 순서를 큐 `o`에 넣는다.
3. `o`가 빌 때까지 현재 원하는 상자와 `q.front()`를 비교한다.
4. 두 상자가 같으면 기본 벨트에서 꺼내 트럭에 싣고 `answer`를 증가시킨다.
5. 그렇지 않으면 현재 원하는 상자와 `s.top()`을 비교한다.
6. 두 상자가 같으면 보조 벨트에서 꺼내 트럭에 싣고 `answer`를 증가시킨다.
7. 어느 쪽에서도 원하는 상자를 꺼낼 수 없다면 기본 벨트의 맨 앞 상자를 보조 벨트로 옮긴다.
8. 기본 벨트까지 비어 더 진행할 수 없다면 반복을 종료하고 `answer`를 반환한다.

## 코드 설명
```cpp
#include <string>
#include <vector>
#include <stack>
#include <queue>

using namespace std;

int solution(vector<int> order) {
    int answer = 0;
    stack<int> s;
    queue<int> q;
    queue<int> o;
    for(int i = 0 ; i < order.size() ; ++i) {
        q.push(i+1);
        o.push(order[i]);
    }
    while(!o.empty()) {
        if(!q.empty() && q.front() == o.front()) {
            ++answer;
            o.pop();
            q.pop();
        }
        else if(!s.empty() && s.top() == o.front()) {
            ++answer;
            o.pop();
            s.pop();
        }
        else if(!q.empty()) {
            s.push(q.front());
            q.pop();
        }
        else break;        
    }
    return answer;
}
```
- `q`는 상자가 번호 순서대로 나오는 기본 컨테이너 벨트이다.
- `s`는 나중에 넣은 상자를 먼저 꺼내는 보조 컨테이너 벨트이다.
- `o.front()`는 현재 트럭에 실어야 하는 상자를 나타낸다.
- 기본 벨트와 보조 벨트에서 상자를 실을 때마다 `answer`를 증가시키고 원하는 순서의 맨 앞 상자를 제거한다.
- 원하는 상자를 어느 곳에서도 꺼낼 수 없고 기본 벨트도 비었다면 이후 상자를 싣는 것은 불가능하므로 반복문을 종료한다.

## 시간 복잡도
- 상자의 개수를 `N`이라고 할 때, 각 상자는 기본 벨트에 한 번 들어가고 한 번 빠진다.
- 보조 벨트로 이동하는 상자도 한 번 들어가고 최대 한 번 빠지며, 큐와 스택의 삽입 및 삭제는 O(1)이다.
- 따라서 전체 시간 복잡도는 O(N)이다.
- 기본 벨트, 보조 벨트, 원하는 순서에 최대 O(N)개의 원소를 저장하므로 공간 복잡도는 O(N)이다.
